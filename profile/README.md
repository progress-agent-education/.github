# Progress Agent Engineering

Progress Agent Engineering helps teams understand, debug, evaluate, and improve AI agents and LLM-powered applications.

AI agents, RAG systems, copilots, and LLM workflows do not behave like traditional request-response software. A single answer may involve prompts, model calls, tool use, retrieval, retries, workflow logic, tokens, costs, and evaluation results. Progress Agent Engineering brings those signals together so teams can see what happened, why it happened, what it cost, and whether the result was good enough to ship.

## What We Work On

- AI observability for agents, RAG systems, copilots, and LLM applications
- AI tracing across prompts, model calls, tools, retrieval steps, latency, tokens, and outputs
- Workflow debugging for agent failures, skipped tools, bad context, retries, and loops
- Cost analysis for token usage, model usage, provider usage, and workflow patterns
- LLM-as-a-Judge evaluations, datasets, experiments, and quality scorecards
- Developer resources for .NET, Python, JavaScript, TypeScript, Semantic Kernel, LangChain, LlamaIndex, AutoGen, Microsoft Agent Framework, Azure OpenAI, OpenAI, and Anthropic

## For Developers

Use these resources when you want to:

- Trace what an AI agent did across prompts, tools, retrieval, and model calls
- Debug agent behavior that looks successful but produces the wrong result
- Understand token usage and estimated cost by model, provider, workflow, or agent
- Create evaluations from production traces or known quality criteria
- Improve your agents over time
- Add observability to an existing .NET, Python, JavaScript, or TypeScript AI application

## Product Status

Progress Agent Engineering is a commercial Progress product. The public resources in this organization are intended to help developers learn, evaluate, and adopt AI observability and evaluation practices. Unless a repository states otherwise, product source code is not open source.
